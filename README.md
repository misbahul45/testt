# To-Do List

Aplikasi to-do list sederhana yang dibuat dengan HTML, CSS, dan JavaScript tanpa framework.

## Fitur

- Menambahkan tugas
- Menandai tugas sebagai selesai
- Menghapus tugas
- Menghapus semua tugas yang sudah selesai
- Menyimpan daftar tugas di `localStorage`
- Tampilan responsif untuk desktop dan perangkat seluler

## Menjalankan Proyek

Buka file `index.html` langsung melalui browser.

Atau jalankan server lokal:

```bash
python3 -m http.server 8000
```

Kemudian buka `http://localhost:8000` di browser.
